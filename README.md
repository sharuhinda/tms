# Project name: Truth Maintenance System

## Project Goals and Description

Основная цель - получить минимальную работоспособную версию Dependency-Directed Truth Maintenance System. Система должна быть пригодна для хранения фактов и их векторных представлений, связывания фактов друг с другом через допущения и причинно-следственные связи, обновления наборов обоснований (justification sets).
